PROJECT NAME : Infra_Track
PROBLEM STATEMENT : Intelligent Data Capture & Schedule-Linking Layer for Infrastructure Project Management: Real-Time Actual Progress Tracking (Planning-to-Execution Bridge)

SOLUTION PROPOSED :  
We proposed a real time middleware layer solution  that captures multi modal site data using drone videos ,site  telematics .
WBS –to –element mapping : Every physical component in the BIM or site zone is hard linked to a WBS (work Breakdown Structure)activity from primavera and MS project .It schedule sink with proposed solution of automated AI driven synchronization with WBS.

TECH STACK USED :
Frontend : html5 , css3 , java script
Beckend : Node.js
Framework : Vanilla java script
Database : MongoDB

TECHNICAL APPROACH :
The goal of this layer is to eliminate manual daily progress by automate data collection from multiple sources using NLP voice to text dictation allows superviors to say “Finished poring zone 8 foundations today ,delayed 2 hours due to Rain” . This system automatically purses it quantitative data .
It includes sensors , mobile apps , BIM object to activity ID mapping and AP bridge.
